# 《Fake Forces 善假于物》—— 核心设计纲要 (v1.0)

> 项目代号：幻觉引擎 (Illusion Engine)
> 开发环境：Godot 4.x (2D)
> 目标平台：PC (Demo)
> 开发周期：10天（3人小组冲刺）
> 核心理念："所谓力，不过是参考系中加速度的幻觉。"

---

## 1. 项目愿景与核心哲学

### 1.1 游戏前引（开场定调）
从牛顿的绝对空间到马赫的遥远星空，引力与惯性力在物理学的底层殊途同归。
在本游戏中，玩家将亲历"真实"与"虚假"的边界——通过切换参考系，利用"虚假力"（惯性力）完成闯关，最终领悟：**力，不过是参考系选择带来的幻觉。**

### 1.2 设计目标（三大支柱）
- **体验目标**：让玩家在"常态（被幻觉欺骗）"与"洞察（看穿幻觉）"之间反复切换，产生强烈的认知失调与解谜爽感。
- **教育目标（隐性）**：直观展示**等效原理**（引力≈惯性力）、**马赫原理**（惯性质量源自宇宙中所有物质的共同作用）及**旋转参考系中的虚假力**（离心力与科里奥利力）。
- **美学目标**：极简几何图形 + 动态旋转粒子星空，配合"实/虚双向箭头"作为视觉语法，营造冷峻科幻感。

## 2. 核心玩法与操作机制

### 2.1 基础键位（极简）
| 操作 | 键位 | 说明 |
| :--- | :--- | :--- |
| 角色移动 | WASD / 方向键 | 上下左右控制角色平面移动（无跳跃键，因为"虚假重力"会改变落点） |
| 洞察模式（灵魂按键） | 按住 Shift | **方案甲（已采纳）**：按住即触发"子弹时间+视觉破译"，松开即恢复常态幻觉 |

### 2.2 两大状态切换（常态 ⇄ 洞察）

| 状态 | 时间流速 | 视觉特征 | 物理表现 |
| :--- | :--- | :--- | :--- |
| 常态（幻觉笼罩） | 1.0倍速（实时） | 背景星空旋转，无额外提示 | 角色受当前幻觉场影响，运动轨迹发生偏转 |
| 洞察模式（真相浮现） | 0.2倍速（子弹时间） | ①星空定格旋转；②角色身上出现**蓝色实线箭头**（你的输入意图）与**红色虚线箭头**（当前承受的虚假力矢量） | 矢量叠加可视化，玩家可精确调整摇杆方向来抵消虚假力 |

## 3. 物理模型（"符实且不难懂"量化体系）

为了兼顾"物理真实"与"高中生理解门槛"，我们只引入 **4个核心参数**，全部在 Inspector 面板中可调。

### 3.1 幻觉强度：G值系统
- **定义**：以游戏内标准重力为基准，`1G = 10 游戏单位/秒²`。
- **显示**：屏幕左上角实时显示 `当前幻觉强度：X.X G`。
- **底层公式**：`虚假力加速度 = - 参考系加速度`（因质量 m 被约去，直接体现伽利略的自由落体定律）。

### 3.2 惯性幻觉（马赫原理的量化）
- **参数**：惯性系数 `η`（取值范围 0.3 ~ 2.5）。
- **作用**：改变角色对真实输入的"响应灵敏度"。
  - `η > 1`：角色变"沉重"（推不动，但撞击障碍物时破坏力极高）。
  - `η < 1`：角色变"轻盈"（飘忽，稍微一推就滑很远）。
- **视觉反馈**：角色周身散发光晕——**红色（重）** / **蓝色（轻）**。

### 3.3 阻力系统（空气/地面阻尼）
- **参数**：阻尼系数 `k`（取值范围 0 ~ 1.0）。
- **公式**：`阻力 F_drag = - k * v`（方向永远与速度相反）。
- **游戏化表现**：
  - `k = 0`：绝对真空（推一下永远停不下来，滑冰手感）。
  - `k = 0.8`：高阻力环境（松手即停，精准定位）。
- **视觉反馈**：阻力越大，角色身后拖尾粒子越浓密。

### 3.4 旋转参考系中的双重虚假力（后期核心）
当关卡中存在旋转核心（角速度 ω）时，玩家会额外承受两种力：
1.  **离心力**：`F_离心 = m * ω² * r`（离旋转中心越远，被甩得越狠）。
2.  **科里奥利力**：`F_科氏 = -2m * (ω × v)`（移动速度越快，横向偏转越离谱，这是产生"幻觉感"最强的力）。

## 4. 关卡演进结构（Demo 10天冲刺版）

Demo仅制作 **1个完整大关卡**，时长 3~5 分钟，严格遵循"A（唯我）→ 过渡（引入物体）→ B（全局旋转）"的教学曲线。

### 阶段 1：唯我幻觉（前 1/3 段）
- **幻觉影响范围**：仅**玩家角色**（方案A）。
- **环境特征**：纯平台跳跃，无任何可交互物体。背景匀速左右加速移动，产生向左/右的虚假重力。
- **教学目的**：强迫玩家按 `Shift` 看清红色箭头，学会用反向操作抵消偏转。**只有通过这一段，玩家才明白"洞察键是保命键"。**

### 阶段 2：唯物过渡（中 1/3 段）
- **幻觉影响范围**：玩家 + 新引入的 **"幻灵方块"**（挂载 `IllusionGroup` 组，且 `is_phantom = true`）。
- **关键机制**：幻灵方块会与玩家受到**完全相同的虚假力**（如一起被吹向右方）。
- **谜题设计**：玩家需要利用被"吹"到特定位置的幻灵方块作为垫脚石，跳过原本过不去的深渊。
- **参照物引入**：场景中同时放置固定不动的 **"绝对方块"**（`is_phantom = false`），它们不受任何幻觉影响，充当玩家的"绝对参考系路标"。

### 阶段 3：旋转共鸣（后 1/3 段 → 最终高潮）
- **幻觉影响范围**：全局万物（方案B完全体）。
- **环境特征**：一个巨大的**旋转核心**占据屏幕中央，产生极强的离心力与科里奥利力。背景马赫星空剧烈旋转。
- **最终谜题**：出口位于天花板高处，但被障碍物封住正常路径。玩家必须**按住 Shift 洞察**，观察红/蓝箭头合成方向，**反向推摇杆**，利用离心力将自己像"甩铁饼"一样精准抛射进唯一出口。
- **胜利演出（非做不可）**：触碰出口瞬间——
  1. 屏幕闪烁白光；
  2. 背景星空猛然定格，旋转停止；
  3. 所有红色虚线箭头炸裂成粒子碎片；
  4. 屏幕中央缓缓浮现主题大字：**"所谓力，不过是参考系中的幻觉。"**
  5. （可选）播放一个低沉的环境音效淡出。

## 5. 技术架构与 Godot 实现蓝图（给程序组）

> 以下内容为 Godot 4 工程的具体实现指引，务必严格遵循。

### 5.1 核心架构：单例管理器
创建 Autoload 脚本 `IllusionManager.gd`：
- 全局变量：`var global_influence_strength : float = 0.0`（0~1，控制环境物体受力比例）。
- 核心方法：`func get_current_fake_vector() -> Vector2`，每一帧根据玩家所在 `Area2D` 的不同，返回当前应施加的虚假力矢量。

### 5.2 物理执行流程（_physics_process 伪代码）
所有受影响的物体（玩家、幻灵方块）统一执行以下叠加逻辑：

	# 在 Player.gd 和 PhantomBlock.gd 中
	func _physics_process(delta):
		# 1. 获取玩家的原始输入（方向向量）
		var input_dir = Input.get_vector("left", "right", "up", "down")
		
		# 2. 从 IllusionManager 获取当前帧的虚假力
		var fake_force = IllusionManager.get_current_fake_vector()
		
		# 3. 应用阻尼（阻力）
		var damping_force = -k * velocity
		
		# 4. 最终速度合成（神之一笔）
		velocity += (input_dir * speed + fake_force + damping_force) * delta
		move_and_slide()

### 5.3 关键节点分组与属性
- **组（Group）**：所有可受幻觉影响的物体，必须添加到 `"IllusionGroup"` 组。
- **脚本导出变量**：`@export var is_phantom : bool = true`。
  - `true`：完全受 `IllusionManager` 的 `global_influence_strength` 影响。
  - `false`：绝缘体，永远不受虚假力（用于制作"绝对方块"）。

### 5.4 洞察模式的具体实现（视觉层）
1. **时间缩放**：`Engine.time_scale = 0.2`（通过 `Input.is_action_pressed("insight")` 触发，松开恢复为 1.0）。
2. **矢量箭头绘制**：在 Player 脚本的 `_draw()` 中：
   - 绘制蓝色实线：`draw_line(position, position + input_dir * 100, Color.BLUE, 3)`
   - 绘制红色虚线：`draw_line(position, position + fake_force.normalized() * 100, Color.RED, 3, true)`（`true` 为虚线）。
3. **星空定格**：在背景 `Shader` 中传入 `uniform float rotation_speed`，洞察模式下强制赋值为 `0`。
