# 第一部分：项目概述

## 1.1 游戏简介

《Fake Forces 善假于物》是一款以**参考系切换**为核心的2D平台解谜游戏。玩家扮演一个身处非惯性参考系中的几何角色，通过按住 `Shift` 进入"洞察模式"看清虚假惯性力的方向，并反向操作抵消幻觉，最终利用这些"不存在"的力完成闯关。

游戏以**马赫原理**和**等效原理**为物理学根基，将"虚假力"（惯性力）作为核心谜题驱动力，而非战斗或躲避的障碍。

## 1.2 核心体验

| 维度 | 描述 |
| :--- | :--- |
| 常态下 | 玩家感觉角色"不听话"、被无形力量推拉，产生认知失调 |
| 洞察下 | 时间变慢，红蓝双箭头显影，玩家从"被幻觉欺骗"转为"主动解析幻觉" |
| 通关后 | 玩家亲历"虚假力从产生到消失"的完整认知闭环，理解"力只是参考系选择的幻觉" |

## 1.3 设计目标（三大支柱）

- **体验目标**：让玩家在"常态"与"洞察"间反复切换，产生强烈的解谜爽感与认知清醒。
- **教育目标（隐性）**：直观展示等效原理、马赫原理、离心力与科里奥利力。
- **美学目标**：极简几何 + 动态粒子星空 + 红蓝双箭头作为核心视觉语言。


# 第二部分：核心玩法与操作机制

## 2.1 基础键位

| 操作 | 键位 | 说明 |
| :--- | :--- | :--- |
| 角色移动 | WASD / 方向键 | 上下左右移动（无跳跃键，因虚假力改变落点） |
| 洞察模式 | 按住 Shift | **方案甲**：按住触发子弹时间+视觉破译，松开恢复常态 |
| 收集尘埃 | 按住 E | 吸引周围"马赫尘埃"（阶段2起可用） |

## 2.2 两大状态切换

| 状态 | 时间流速 | 视觉特征 | 物理表现 |
| :--- | :--- | :--- | :--- |
| 常态 | 1.0倍速 | 背景星空旋转，无箭头 | 角色受当前幻觉场影响，轨迹偏转 |
| 洞察模式 | 0.2倍速 | ①星空定格；②蓝色实线箭头（玩家意图）；③红色虚线箭头（虚假力矢量） | 物理计算**完全相同**，仅视觉揭示矢量合成 |

> **关键原则**：洞察模式**不关闭幻觉**，而是**揭示幻觉的几何构成**。物理层永远不分支，视觉层承担全部差异。

## 2.3 洞察能量条（已采纳）

- 按住 `Shift` 进入洞察模式时，**持续消耗能量条**。
- 常态下，能量条以**3秒满格**的速度自动恢复（具体数值待调试）。
- 能量耗尽时，洞察模式强制退出。
- **设计意义**：玩家无法全程慢放，必须在关键时刻短暂开启洞察，凭记忆完成操作。

> **开发备注**：能量条使用 `Timer` 节点控制恢复，`Energy` 变量在 `_process` 中持续消耗。


# 第三部分：物理模型（四个核心量化指标）

所有物理量在底层仅依赖以下四个参数。它们全部作为 `Area2D` 的导出变量，关卡设计师无需碰代码即可调节。

## 3.1 G值（幻觉强度标尺）

| 维度 | 内容 |
| :--- | :--- |
| 定义 | 1G = 10 游戏单位/秒² |
| 物理层 | `fake_force = G值 × 方向` |
| UI | 左上角实时显示 `当前幻觉强度：X.X G`（颜色绿→黄→红） |
| 视觉 | 屏幕边缘红晕宽度与G值成正比 |
| 音效 | 低频嗡鸣音量随G值升高 |

## 3.2 惯性系数 η（质量幻觉）

| 维度 | 内容 |
| :--- | :--- |
| 定义 | 取值范围 0.3 ~ 2.5 |
| 物理层 | `输入贡献 = input_dir × speed / η`。η越大越重，越小越轻 |
| 谜题 | η > 1.5 可撞碎幻灵方块；η < 0.6 可飘过尖刺 |
| 视觉 | 角色光晕：η > 1.2 红色（重），η < 0.8 蓝色（轻） |

## 3.3 阻尼系数 k（阻力幻觉）

| 维度 | 内容 |
| :--- | :--- |
| 定义 | 取值范围 0 ~ 0.95 |
| 物理层 | `damping_force = -k × velocity` |
| 谜题 | k≈0 为"真空"（滑行难停）；k≈0.9 为"沥青"（松手即停） |
| 视觉 | 角色身后拖尾长度与k成反比 |

## 3.4 角速度 ω（旋转幻觉，阶段3专属）

| 维度 | 内容 |
| :--- | :--- |
| 定义 | 取值范围 0 ~ 3.0 rad/s |
| 物理层 | 离心力 = m × ω² × r；科里奥利力 = -2m × (ω × v) |
| 谜题 | 玩家利用离心力"甩"向高处出口 |
| 视觉 | 旋转核心自转速度、背景星空转速均与ω绑定 |

## 3.5 四个参数联动总览

| 参数 | 符号 | 范围 | 手感影响 | 谜题影响 | 视觉影响 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 幻觉强度 | G | 0.0~3.0 | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ |
| 惯性系数 | η | 0.3~2.5 | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ |
| 阻尼系数 | k | 0.0~0.95 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐ |
| 角速度 | ω | 0.0~3.0 | ⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ |


# 第四部分：关卡设计（Demo 10天冲刺版）

Demo为 **1个完整大关卡**，时长 3~5 分钟，分为三个阶段。

## 4.1 阶段1：唯我幻觉（引入期）

| 项目 | 内容 |
| :--- | :--- |
| 幻觉范围 | 仅**玩家角色**（方案A） |
| 环境 | 纯平台跳跃，无交互物体，背景左右匀速加速移动 |
| G值 | 约 0.8（向左或向右持续偏转） |
| 教学目的 | 玩家第一次被"无形力量"推偏，按下Shift洞察首次看到红色箭头，学会反向抵消 |
| 触发条件 | 进入此区域即自动生效，G值恒定 |
| 关键设计 | **首次受到虚假力时不弹出文字**——让玩家自己困惑、主动按Shift寻找答案。只有首次按Shift后才显示一次："没有人在推你。红色箭头是你所在参考系正在加速的证明。" |

**具体谜题**：一个简单的平台跳跃，但向右跳时角色被向左拉偏，掉下深渊两次后，玩家本能按住Shift看到红色箭头指向左，于是向右多走两步抵消，成功通过。

## 4.2 阶段2：唯物过渡（发展期）

| 项目 | 内容 |
| :--- | :--- |
| 幻觉范围 | 玩家 + **幻灵方块**（挂载 IllusionGroup 组，is_phantom = true） |
| 环境 | 加入可交互的幻灵方块和绝对方块（is_phantom = false） |
| G值 | 约 1.2（偏转力度增强） |
| 新机制 | **马赫尘埃**（已采纳）出现在本阶段，按住E收集，消耗可调整η |
| 教学目的 | ①幻灵方块会像玩家一样被虚假力吹动，可用于垫脚；②绝对方块纹丝不动，充当绝对参考系路标；③尘埃系统让玩家主动控制轻重 |

**具体谜题**：
- 一个深渊，正常跳不过去。深渊上方悬浮一个幻灵方块，被G值吹到右侧边缘。
- 玩家需等待方块被吹到合适位置后跳上去，再跳到对岸。
- 附近有2~3个马赫尘埃可收集，收集后按E降低η，角色变轻，可跳过更远距离。
- 绝对方块放置在深渊正中央作为"锚点"，让玩家对比感受到"只有我在被吹，它没有"的认知反差。

## 4.3 阶段3：旋转共鸣（高潮期）

| 项目 | 内容 |
| :--- | :--- |
| 幻觉范围 | **全局万物**（方案B完全体） |
| 环境 | 中央巨大**旋转核心**（ω ≈ 1.5 rad/s），产生离心力与科里奥利力 |
| G值 | 随距核心距离变化（r越大G越大） |
| 特殊机制 | 科里奥利力首次激活（跑得越快偏得越狠） |
| 教学目的 | 利用离心力将自己"甩铁饼"般抛射进高处出口 |

**常规解法**：
- 出口位于天花板高处，被障碍物封堵正常路径。
- 玩家站在旋转核心的特定半径处，按住Shift洞察，观察红/蓝箭头合成方向。
- 反向推摇杆，利用离心力将角色沿抛物线甩出，落入出口。
- 触碰出口触发胜利演出。

**隐藏解法（已采纳）**：
- 玩家也可以**不反抗科里奥利力**，而是**顺应红箭头方向加速奔跑**。
- 角色会沿极端螺旋轨迹被甩到出口下方的**隐藏平台**上。
- 该平台常态下被视觉遮蔽，仅在**洞察模式下隐约可见**（半透明）。
- 意义：强化"顺应幻觉也可以过关，没有绝对正确路径"的主题。

## 4.4 胜利演出

触碰出口瞬间依次执行：
1. 屏幕闪烁白光
2. 背景星空猛然定格，旋转停止
3. 所有红色虚线箭头炸裂成粒子碎片
4. 屏幕中央缓缓浮现主题大字：**"所谓力，不过是参考系中的幻觉。"**
5. 2秒后，画面淡出至纯黑
6. 最后一行字浮现："你刚才看到的一切，都是你选择相信的幻觉。"
7. 低沉重低音单音响起，Demo结束

## 5.1 核心架构：单例管理器

创建 Autoload 脚本 `IllusionManager.gd`：

    var global_influence_strength : float = 0.0  # 0~1，控制环境物体受力比例
    var current_fake_vector : Vector2 = Vector2.ZERO
    var current_g_value : float = 0.0
    var current_omega : float = 0.0
    
    func get_current_fake_vector() -> Vector2:
        return current_fake_vector
    
    func get_current_g() -> float:
        return current_g_value

## 5.2 物理执行流程（_physics_process）

所有受影响的物体（玩家、幻灵方块）统一执行：

    func _physics_process(delta):
        var input_dir = Input.get_vector("left", "right", "up", "down")
        var fake_force = IllusionManager.get_current_fake_vector()
        var damping_force = -k * velocity
        velocity += (input_dir * speed / eta + fake_force + damping_force) * delta
        move_and_slide()

> **关键**：此逻辑**不**因是否处于洞察模式而做任何分支判断。`Engine.time_scale` 只影响视觉播放速度，不影响 `_physics_process` 的 `delta`。

## 5.3 关键节点分组与属性

- **组（Group）**：`"IllusionGroup"` — 所有受幻觉影响的物体（玩家、幻灵方块）必须加入。
- **脚本导出变量**：`@export var is_phantom : bool = true`
  - `true`：受 `global_influence_strength` 影响
  - `false`：绝缘体（绝对方块），不受任何虚假力

**能量条逻辑**：

    var insight_energy : float = 100.0
    const ENERGY_DRAIN : float = 20.0   # 每秒消耗
    const ENERGY_RECOVERY : float = 33.3 # 每秒恢复（3秒满）
    
    func _process(delta):
        if Input.is_action_pressed("insight") and insight_energy > 0:
            insight_energy -= ENERGY_DRAIN * delta
            # 进入洞察模式
        else:
            insight_energy += ENERGY_RECOVERY * delta
            insight_energy = min(insight_energy, 100.0)
            # 退出洞察模式

# 附录：AI Agent 开发指引

> 本节专门为 **AI 辅助编程工具**（如 Cursor、Copilot、ChatGPT）提供上下文摘要。

## A.1 项目类型

Godot 4.x 2D 平台解谜游戏，核心是**非惯性参考系下的物理模拟**。

## A.2 核心脚本结构（按开发顺序）

1. `IllusionManager.gd`（Autoload）：全局单例，存储 `current_fake_vector`、`current_g_value`、`global_influence_strength`。
2. `Player.gd`（CharacterBody2D）：移动逻辑（速度合成）、能量条、尘埃收集、洞察模式切换、箭头绘制（`_draw`）。
3. `PhantomBlock.gd`（RigidBody2D 或 CharacterBody2D）：幻灵方块，`is_phantom` 控制是否受力。
4. `IllusionZone.gd`（Area2D）：导出变量 `g_value`、`eta`、`damping`、`omega`、`direction`，进入/退出时更新 IllusionManager。
5. `Dust.gd`（Area2D）：马赫尘埃，按 E 时被吸向玩家。
6. `RotatingCore.gd`（Node2D）：阶段3旋转核心，驱动 ω 和背景星空旋转。
7. `VictoryTrigger.gd`（Area2D）：触碰时触发胜利演出。

## A.3 关键参数默认值

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `speed` | 200 单位/秒 | 角色最大移动速度 |
| `eta` | 1.0 | 中性惯性系数 |
| `damping` | 0.5 | 默认阻尼 |
| `ENERGY_MAX` | 100.0 | 能量条最大值 |
| `ENERGY_DRAIN` | 20.0/秒 | 洞察消耗速度 |
| `ENERGY_RECOVERY` | 33.3/秒 | 能量恢复速度（3秒满） |

## A.4 重要约束

- **物理层不分模式**：`_physics_process` 不因洞察模式做分支判断。
- **所有幻觉参数来自 Area2D**：不在脚本中硬编码 G 值或 ω。
- **极简几何**：不要引入复杂精灵或动画，保持白色圆形 + 三角形指示器。
