# 《Fake Forces》—— 物理空间解密·完整设计文档 v2.0（精简重构版）

> 项目代号：幻觉引擎 (Illusion Engine)  
> 开发环境：Godot 4.x (2D)  
> 目标平台：PC (Demo)  
> 开发周期：10天（3人小组冲刺）  
> 核心哲学："所谓力，不过是参考系中加速度的幻觉。"

# 第一部分：项目定位与核心哲学

## 1.1 游戏定位

《Fake Forces》是一款以 **"参考系切换"** 为核心的2D平台解谜游戏。

游戏不设剧情、不设世界观、不设角色背景。玩家面对的是一个纯粹由物理定律与几何空间构成的谜题集合——唯一的敌人是**参考系本身**。

## 1.2 核心体验

| 维度 | 描述 |
| :--- | :--- |
| 常态下 | 玩家的移动被"无形力量"推拉偏转，轨迹不可预测，产生认知失调 |
| 洞察下 | 时间变慢，玩家看清"虚假力"的矢量方向，精确规划路径 |
| 通关后 | 玩家理解"同一运动在不同参考系中呈现不同表象"，完成物理认知闭环 |

## 1.3 设计目标

- **解谜目标**：让玩家通过"识别虚假力 → 规划路径 → 执行操作"三步解决每个关卡。
- **教育目标（隐性）**：直观展示**等效原理**（惯性力≈引力）、**非惯性参考系中的运动合成**、**离心力与科里奥利力的几何来源**。
- **美学目标**：极简几何图形 + 动态矢量箭头 + 冷色调，营造"实验室/教学模拟器"般的纯净感。


# 第二部分：核心机制定义

## 2.1 基础移动逻辑

> **最终运动 = 玩家输入 + 虚假力矢量 + 阻尼力**

三个分量同时作用于角色，叠加后产生最终运动轨迹。

- **玩家输入**：WASD/方向键，代表玩家的操作意图。
- **虚假力矢量**：由场景中的"幻觉场"产生，是独立矢量，与玩家输入做加法叠加。
- **阻尼力**：抵抗运动，决定角色"滑行"还是"急停"的手感。

## 2.2 两大状态

| 状态 | 触发方式 | 效果 |
| :--- | :--- | :--- |
| 常态 | 默认 | 角色按完整物理公式运动，玩家凭感觉操作 |
| 洞察模式 | 按住 `Shift` | ①时间减慢至0.2倍速；②箭头可视化（同比例，合力=运动可验证）：横向=蓝实线(输入)+红虚线(虚假力)+绿实线(系统阻力：阻尼+空中重力)；旋转=蓝(输入)+红(惯性力)+绿(系统阻力：圆盘向心力)；切换参考系另+金(目标向心力)+紫(合力=蓝+红)；③屏幕左下角显示箭头图例；④玩家可精确规划路径 |

> **关键原则**：洞察模式**不关闭幻觉**，只是**揭示幻觉的几何构成**。物理计算全程一致。

## 2.3 能量限制

- 洞察模式持续消耗能量条；普通洞察最长 **5 秒**，含尘埃关卡每收集 1 枚尘埃 +1 秒。
- 常态下能量条自动恢复（**1 秒满格**）。
- 参考系"切换洞察"（Shift 切入直到同步）**无限时**。
- 能量耗尽时强制退出洞察模式。
- `R` 键或暂停菜单"重开游戏"可随时**重开当前关卡**（回到关卡起点）。
- **设计意义**：限制"上帝视角"使用时间，要求玩家在看清矢量后记住并执行。

## 2.4 核心交互

| 操作 | 键位 | 用途 |
| :--- | :--- | :--- |
| 移动 | WASD / 方向键 | 控制角色 |
| 洞察模式 | 按住 `Shift` | 进入子弹时间+矢量可视化 |
| 交互/收集 | `E` | 收集场景元素或触发机关 |


# 第三部分：物理参数与谜题映射

## 3.1 四个核心参数

| 参数 | 符号 | 范围 | 物理作用 | 谜题角色 |
| :--- | :--- | :--- | :--- | :--- |
| 幻觉强度 | G | 0.0 ~ 3.0 | 虚假力的大小（1G = 10单位/秒²） | 决定偏转力度，G值越高补偿越大 |
| 惯性系数 | η | 0.3 ~ 2.5 | 输入响应灵敏度 | η>1.5可撞碎物体；η<0.6可飘过陷阱 |
| 阻尼系数 | k | 0.0 ~ 0.95 | 速度衰减率 | k≈0滑行难停；k≈0.9松手即停 |
| 角速度 | ω | 0.0 ~ 3.0 | 旋转参考系旋转速度 | 产生离心力与科里奥利力 |

## 3.2 参数与谜题的对应关系

| 参数 | 由参数产生的谜题类型 | 玩家需要做的事 |
| :--- | :--- | :--- |
| G值 | 恒定偏转/突变偏转 | 观察G值变化，反向补偿移动方向 |
| η | 轻重切换谜题 | 收集尘埃主动调节η，改变通过方式 |
| k | 滑行/急停谜题 | 根据k值预判刹车距离与落点 |
| ω | 旋转抛射谜题 | 计算角度与力度，利用离心力到达目标 |


# 第四部分：具体关卡设计（三阶段教学曲线）

Demo制作 **1个完整大关卡**，时长约 5~8 分钟，分为三个阶段，共包含 **7个具体谜题**。

## 4.1 总体结构

| 阶段 | 名称 | 包含谜题数 | 幻觉范围 | 教学产出 |
| :--- | :--- | :--- | :--- | :--- |
| 阶段1 | 线性偏转 | 3个 | 仅玩家 | 学会识别虚假力并反向补偿 |
| 阶段2 | 交互与资源 | 2个 | 玩家 + 幻灵方块 | 学会利用环境物体 + 主动控制自身惯性 |
| 阶段3 | 旋转场 | 2个 | 全局万物 | 掌握旋转参考系下的矢量合成 |


## 4.2 阶段1：线性偏转（3个谜题）

### 关卡1-1：初识偏转

**场景描述**：
- 一个水平长平台，起点在左端，终点在右端。
- 平台中间有一处缺口（宽约2个角色身位），缺口下方是深渊。
- 整个区域施加 **G = 0.8，方向向左** 的恒定虚假力。

**物理参数**：
- G = 0.8（向左）
- η = 1.0（标准惯性）
- k = 0.6（适中阻尼）
- ω = 0

**谜题设计**：
- 玩家站在起点，按 `D` 键向右走——角色却明显地向左偏转。
- 第一次尝试：玩家直线向右跳，因虚假力被拉向左方，掉入缺口，死亡。
- 第二次尝试：玩家**仅凭感觉**向右多走两步再跳，可能成功，但需要多次试错。
- 引导发现：玩家按下 `Shift` 进入洞察模式，看到红色虚线箭头指向左方。
- 解法：红色箭头提示玩家需要向右 **额外补偿 0.8G 的偏移量**。玩家在洞察模式下看清方向后，松开Shift，在常态中向右多走约30%的额外距离，成功跳过缺口。

**通关条件**：抵达平台右端的发光终点区域。

**玩家习得**："按住Shift可以看到红色箭头——它告诉我在哪个方向受到了额外的拉动。"


### 关卡1-2：变向偏转

**场景描述**：
- 两个平台上下交错，玩家需要从下层跳到上层。
- 区域被分为两段：
  - **左半段**：G = 1.0，方向向右。
  - **右半段**：G = 1.0，方向向左。
- 两个半段的交界处有明显的视觉指示（如颜色渐变）。

**物理参数**：
- G = 1.0（左段向右，右段向左）
- η = 1.0
- k = 0.5
- ω = 0

**谜题设计**：
- 玩家从下层左侧出发，跳到右段时，虚假力突然从向右变为向左。
- 玩家若按之前的补偿习惯操作，会被反向拉偏，撞墙或跌落。
- 解法：玩家需要在到达边界前**松开Shift洞察**，提前看到红色箭头方向将反转，从而在跨越瞬间调整补偿方向。
- 该谜题训练玩家**预判参数变化**，而非简单机械记忆。

**通关条件**：抵达上层右侧的发光终点区域。

**玩家习得**："虚假力方向可以变化，我需要在边界处切换补偿方向。"


### 关卡1-3：双向往返

**场景描述**：
- 一个 U 型通道：左侧向下、底部水平、右侧向上。
- 玩家需要从左侧顶部进入，从右侧顶部离开。
- 全程 G = 1.5，方向**始终向右**。

**物理参数**：
- G = 1.5（向右恒定）
- η = 1.0
- k = 0.4（较低阻尼，滑行感强）
- ω = 0

**谜题设计**：
- U型通道左侧：玩家向下走时，向右的虚假力把角色推向右侧墙壁（看似"有利"，因为强制让角色走向底部）。
- U型通道右侧：玩家向上走时，向右的虚假力**把角色推向右侧墙壁的反方向**（实际上是把角色"压"向墙壁，阻碍上升）。
- 解法：在上升段，玩家需要**向左额外补偿**来抵消向右的虚假力，才能竖直向上爬升。
- 难度在于：玩家在左侧段的"有利经验"在右侧段会变成"误导"——需要识别出同一参数在不同路径方向上的不同影响。

**通关条件**：抵达U型右侧顶部的发光终点区域。

**玩家习得**："同样的虚假力，在不同路径方向上会产生不同效果——需要根据当前运动方向重新评估补偿策略。"


## 4.3 阶段2：交互与资源（2个谜题）

### 关卡2-1：幻灵方块垫脚

**场景描述**：
- 一个宽阔的深渊（宽约6个角色身位），正常跳跃无法通过。
- 深渊上方悬浮着一个 **幻灵方块**（蓝色半透明），它会受到与玩家相同的虚假力。
- 区域 G = 1.2，方向向左。
- 深渊右侧放置一个 **绝对方块**（橙色实心，不受力），作为参照物。

**物理参数**：
- G = 1.2（向左恒定）
- η = 1.0
- k = 0.5
- ω = 0

**谜题设计**：
- 玩家向右跳跃，因虚假力被拉向左方，掉入深渊。
- 幻灵方块同样受到向左的虚假力，会从初始位置缓慢向左漂移。
- 解法：玩家需**等待**幻灵方块被虚假力"吹"到深渊的某个中间位置（即深渊中心的左侧某处），然后以幻灵方块为中间跳板，先跳到方块上，再跳到对岸。
- 时间窗口：方块持续向左漂移，约3秒后移出最佳位置范围（太靠左则无法作为跳板）。玩家需把握时机，在方块处于"最佳垫脚区"时起跳。
- 绝对方块作为参照物，始终静止，让玩家对比感受到"只有我和这个方块在被吹"。

**通关条件**：抵达深渊右侧的发光终点区域。

**玩家习得**："虚假力不仅影响我，也影响场景中的一些物体——我可以利用这些物体作为移动平台。"


### 关卡2-2：尘埃与轻重切换

**场景描述**：
- 一条狭窄通道，分为两段：
  - **第一段**：布满尖刺的地面，但上方有紧贴天花板的狭小空间（仅容一个角色身位）。
  - **第二段**：一堵薄墙（由幻灵方块构成），需要用"重"的状态撞碎。
- 通道中散落着 3 颗 **马赫尘埃**（发光粒子团）。

**物理参数**：
- G = 1.0（向右恒定）
- η = 1.0（初始标准状态）
- k = 0.6
- ω = 0

**谜题设计**：
- 尖刺段：玩家正常通过会踩到尖刺死亡。解法：按住 `E` 消耗 1 颗尘埃，将 η 从 1.0 降低至 0.5（角色变轻），然后角色可以"飘"过尖刺上方而不触发伤害。
- 薄墙段：轻状态无法撞碎幻灵方块墙。解法：再消耗 1 颗尘埃，将 η 从 0.5 提升至 1.8（角色变重），撞击薄墙即可将其撞碎，开辟通路。
- 剩余 1 颗尘埃作为"容错资源"，玩家如操作失误可再次调整。
- 玩家需要**合理分配尘埃数量**——如果用完则无法通关，需要重来。

**通关条件**：通过两段障碍后抵达通道末端的发光终点区域。

**玩家习得**："我可以主动改变自己的惯性系数——变轻可以飘过陷阱，变重可以撞碎障碍。尘埃是有限的资源，需要合理分配。"


## 4.4 阶段3：旋转场（2个谜题）

### 关卡3-1：离心抛射

**场景描述**：
- 场景中央是一个巨大的 **旋转核心**（圆盘状，带有旋转动画）。
- 出口位于天花板高处，被实体障碍封堵，无法直接抵达。
- 玩家可以站在旋转核心周围的环形平台上。
- 整个场景施加 ω = 1.5 rad/s 的恒定旋转（方向顺时针）。

**物理参数**：
- G = 动态（0~3.0，距离核心越远越大）
- η = 1.0
- k = 0.3（低阻尼，便于抛射滑行）
- ω = 1.5 rad/s（顺时针）

**谜题设计**：
- 玩家站在环形平台某处，受到向外甩的离心力。距离核心越远，G值越大（离心力越大）。
- 常规解法：玩家需站在**离心力最强**的外环位置（约 r=6 单位），按住 `Shift` 进入洞察模式，看到红色虚线箭头指向外。
- 玩家需要**反向推摇杆**（即向核心方向推），蓄力后松开（利用离心力将角色"甩"出），角色沿抛物线被抛射至天花板的出口。
- 关键判断：推摇杆的方向与力度决定抛射角度。如果推得太直（90度），会撞到天花板侧面；推得太偏，会飞出场景边界。
- 玩家需在洞察模式下**多次观察矢量合成方向**，微调推杆角度，才能精确命中出口。

**隐藏解法（可选）**：
- 玩家若**不反抗离心力**，而是顺着红色箭头方向（向外）奔跑，角色会被甩向更外圈。
- 在外圈的特定位置（r=8 单位），存在一个隐藏平台，在洞察模式下呈半透明可见。
- 抵达隐藏平台后，角色可沿一条隐蔽路径抵达出口。
- 意义：提供"顺应幻觉也能过关"的替代路径，丰富解题思路。

**通关条件**：抵达天花板高处的发光出口区域。

**玩家习得**："旋转参考系中，运动轨迹由离心力与玩家输入的合成决定——我需要站在正确半径，用正确角度抵消/利用离心力。"


### 关卡3-2：科里奥利螺旋

**场景描述**：
- 场景同关卡3-1，但增设了更复杂的障碍：在环形平台到出口之间，分布着三个移动障碍物（缓慢旋转的弧形挡板）。
- 障碍物的旋转速度与核心同步（ω = 1.5 rad/s）。
- 出口位置移动至更刁钻的角度（约225°方向）。

**物理参数**：
- G = 动态（0~3.0）
- η = 1.0
- k = 0.2（更低阻尼，便于长距离滑行）
- ω = 1.5 rad/s（顺时针）

**谜题设计**：
- 离心力将玩家甩向外侧，但**科里奥利力**会同时作用——玩家奔跑速度越快，科里奥利力造成的横向偏转越大。
- 解法：玩家需在跑动过程中**同时考虑离心力（径向）与科里奥利力（切向）**，设计一条螺旋路径。
- 具体步骤：
  1. 玩家站在特定半径处（r=5），按住 Shift 洞察，看到红色虚线箭头由两个分量组成（径向向外的离心力 + 切向的科里奥利力）。
  2. 玩家需反向推摇杆，既要对抗向外的力，又要对抗横向偏转的力。
  3. 玩家按计算好的角度奔跑，沿一条螺旋轨迹穿越三个移动障碍物的间隙。
  4. 最终抵达出口。
- 障碍物间隙每约 2 秒开放一次，玩家需在洞察模式下规划好时机与路径。

**通关条件**：穿越障碍物后抵达出口区域。

**玩家习得**："在旋转参考系中高速移动时，科里奥利力会造成横向偏转——跑得越快偏得越狠。最终运动是所有分量的矢量合成。"


## 4.5 胜利反馈

触碰出口后依次执行：
1. 屏幕闪烁白光，所有声音骤停。
2. 场景中的旋转核心停止旋转，星空背景定格。
3. 所有红色虚线箭头炸裂成粒子碎片，缓缓消散。
4. 屏幕中央浮现核心哲学：
   > **"所谓力，不过是参考系中加速度的幻觉。"**
5. 画面停留 3 秒后，淡出至主菜单。


# 第五部分：美术与交互规范

## 5.1 视觉规范

| 元素 | 设计 | 颜色/样式 |
| :--- | :--- | :--- |
| 角色 | 白色圆形 + 小型方向指示三角 | 白色 (#FFFFFF) |
| 常规地面/平台 | 实心矩形 | 灰色 (#666666) |
| 幻灵方块 | 半透明矩形，带呼吸光效 | 蓝色 (#4488FF, 0.5 α) |
| 绝对方块 | 实心矩形，带边框高亮 | 橙色 (#FF8800) |
| 尖刺陷阱 | 倒三角形排列 | 红色 (#FF3333) |
