# 第一部分：游戏导言（开场）

> **注**：以下导言已作为游戏开场演出接入（`OpeningSequence.gd`，9段逐行淡入淡出，**按空格跳过**，画面下方有提示）。

你是"深空"号空间探索船的一名船员，你和成员早已经忘却了为何离开地球，在星图上早已找不到那个炽热的光点和蓝色的摇篮。

有人，不，是飞船中的系统，日复一日的展示着"先驱者"的肖像。你不知道他们是谁，但是有一点可以确定，你们是他们带领来的。

在那些语录中，你们被赋予了深深的期望——

> 探索未知的深空，不要问归途何方。

这似乎就是你们一生的使命。

偶然一日，你在舰板闲逛，发现了一位头发花白的中年人，他似乎已经停止了呼吸，机器人正将他的遗体清理掉。他坐的椅子旁，有一本发着苍蓝光芒的智能化记事本。

那就去吧。

# 第二部分：核心哲学——《善假于物》

## 关于 "fake" 的三点理解

### 1. "虚假"的语义

fake，虚假的，通常是形容词，这里用做"力"的修饰。

这种力，是指游玩时玩家直接看见的那个"不存在的推力"，也是指向剧情真相的那个虚构的动力。

### 2. 假的一定是不好的吗？

恐怕不是。

在探索中，假的力可供我们利用——越过难以逾越的地方。

而对于剧情中的人类——他们为虚假的陨石价值所蒙蔽；而领航员凡·赫特克，却利用虚假的死亡重构地外空间的意义。

最终，为了追求真相，我们也将跃向那虚假力的极点……

### 3. "善假于物"的双关

《Fake Forces》的中文名《善假于物》，似乎带有一种双关的意味。

- 只看原文："君子生非异也，善假于物也"——善于借助外物。玩家正是"假"那虚假之力，跨越难关。
- 用谐音来理解，也别有一番趣味。

> 双关："假"既作"借助"解，亦作"虚假"解——借助虚假之力，抵达真实。

# 第三部分：故事背景（深空号）

## 地球的陨落

月球因过度开发而碎裂，陨石频发。但陨石本身成为资本的猎物——谁控制了地外开发权，谁就控制了未来。
普通人被商业宣传与信息茧房淹没，逐渐丧失了对深空的全部兴趣。

## 领航员凡·赫特克的抉择

原领航员凡·赫特克曾试图用技术手段清除陨石，但被资本叫停。
在撤离深空号的最后时刻，他与志同道合的队员，**强行催眠所有资本头领**，将飞船驶出太阳系。

不是为了征服——**是为了让人类重新看见宇宙。**

## 系统的诞生

资本头领与凡·赫特克自己，经由"模拟死亡与知识导入"，成为维持飞船运行的"船员"。
他们的记忆被抹除，人格被系统化，日复一日执行着飞船的功能。

先驱者的肖像每日循环播放，语录响彻船舱：

> "探索未知的深空，不要问归途何方。"

——这曾是凡·赫特克篡改后的指令。但在遗忘中，它变成了空壳。

## 老人之死

他是唯一存活到最后的人。
也是唯一记录到最后的人。
他的记事本，记录着飞船各舱室的"虚假力"数据，以及一段被折叠在数据中的真相。

## 终局：黑洞

你拾起记事本，看到一条简单的航路——指向离你们最近的黑洞。

"去哪？或许，唯一的线索，只会在那儿。"

那就去吧。

# 第四部分：人物

## 凡·赫特克（领航员 / 老人 / 先驱者）

- 深空号原领航员。
- 试图清除陨石被资本叫停，最终强行催眠资本头领，驾船驶出太阳系。
- 为让人类重新看见宇宙，不惜牺牲自己成为系统的一部分。
- 唯一存活到最后的人，唯一记录到最后的人。
- 结局中，他留下遗言（以“ ”标示、暖色呈现，不再绘制面孔）：“该说些什么呢，呵呵...”“恭喜你，小伙子，你看见了我留下的记号，来到了这里，看到了‘真相’”“你究竟是谁呢？我的同僚，还是，我曾经的敌人？”“不过这些都已无关紧要了。”

## 先驱者（被系统化的船员们）

- 资本头领与凡·赫特克，经由模拟死亡与知识导入，成为维持飞船运行的"船员"。
- 记忆被抹除，人格被系统化。
- 他们的肖像被系统日复一日展示，语录在遗忘中沦为空壳。

## 系统

- 飞船的智能中枢，也是"催眠"的执行者。
- 它展示先驱者的肖像、播放语录，用虚假力牵引船员——它是"参考系的加速度"，是无形的手。

## 玩家（船员）

- "深空"号的一名船员，早已忘却为何离开地球。
- 你在系统的牵引下移动，在洞察中短暂看见真相。
- 你拾起记事本，循着航路跃向黑洞——为了真相。

# 第五部分：核心隐喻

| 物理概念 | 叙事隐喻 |
| :--- | :--- |
| 虚假力（惯性力） | 系统对人的无形牵引——你以为你在自主移动，实则是系统在推你 |
| 参考系切换 | 从"被催眠"走向"觉醒"的行为映射 |
| 洞察模式 | 短暂触摸"被遗忘的真实" |
| G值 | 系统控制的强度——偏转越猛烈，你越难以察觉自己是被牵引的 |
| η（惯性系数） | 你的"自我"强度——越低越容易被裹挟，越高越笨拙但更具破坏性 |
| k（阻尼系数） | 系统对"自由意志"的压制——越高，自主移动越难延续 |
| ω（角速度） | 系统控制的非线性扭曲——转向越剧烈，方向感越模糊 |
| 马赫尘埃 | 老人留下的碎片化数据，散落在飞船各处 |
| 黑洞 | 唯一一个把"物理幻觉"与"叙事幻觉"同时压缩到极限的地方——在那里，时间折叠，过去重新显现 |

# 第七部分：叙事机制

## 老人的记事本（核心道具）

- **双重功能**：①关卡解锁器——记录各舱室航路与虚假力数据，预判该区域的移动偏转；②剧情碎片揭示——特定虚假加速度下浮现隐藏文字。
- **交互**：始终显示在屏幕左下角；在特定区域（阶段进入、G值突变、旋转核心启动）发光，按 `F` 阅读。
- **共 5 页**：第1~3页（阶段2笔记三段）、第4页（黑洞前最终文字）、第5页（隐藏解法"不是逃出去。是跳进去。"）。
- **翻页**：阅读中按 `←`/`→`（或 A/D）前后翻页，`F`/`Esc` 关闭。
- 碎片逐段解锁、不重复；触发条件由 G 值 / ω / **区域进入事件**驱动，与物理耦合（v3.0 §5.1 约束4）。

## 马赫尘埃

- 散落在飞船各舱室中的发光粒子团，按住 `E` 收集，可消耗调整 η（变重/变轻）。
- **叙事含义**：老人留下的数据残片，被飞船系统视为"噪音"而未清除。收集它们，是在一点点恢复"被抹除的过去"。

## 三幕悲剧结构

| 幕 | 名称 | 场景 | 叙事推进 |
| :--- | :--- | :--- | :--- |
| 1 | 系统的牢笼 | 深空号内部 | 第一次感到"不听话"→ 看见红色箭头 → 认知觉醒的起点 |
| 2 | 幻觉的外延 | 飞船气闸 + 天体表面 | 主动利用幻觉（控制轻重）→ 碎片揭示地球陨落 |
| 3 | 真相的折叠 | 黑洞附近 | 最终谜题 → 跃入黑洞 → 时空折叠 → 老人的遗言与旁白逐段浮现 → 感谢字幕"感谢游玩《Fake Forces 善假于物》" → **自动退出**；背景音乐 "The thinking of star"（110.55s），演出时间按音乐时长等比缩放、**结束时刻与音乐同步** |
