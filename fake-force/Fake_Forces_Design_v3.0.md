# 第一部分：叙事基石（所有设计的顶层纲领）

## 1.1 故事背景

### 地球的陨落
月球因过度开发而碎裂，陨石频发。但陨石本身成为资本的猎物——谁控制了地外开发权，谁就控制了未来。普通人被商业宣传与信息茧房淹没，逐渐丧失了对深空的全部兴趣。

### 老人的抉择
原领航员曾试图用技术手段清除陨石，但被资本叫停。在撤离深空号的最后时刻，他与志同道合的队员，**强行催眠所有资本头领**，将飞船驶出太阳系。

不是为了征服——**是为了让人类重新看见宇宙。**

### 系统的诞生
资本头领与老人自己，经由**模拟死亡与知识导入**，成为维持飞船运行的"船员"。他们的记忆被抹除，人格被系统化，日复一日执行着飞船的功能。

先驱者的肖像每日循环播放，语录响彻船舱：

> "探索未知的深空，不要问归途何方。"

——这曾是老人篡改后的指令。但在遗忘中，它变成了空壳。

### 老人之死
他是唯一存活到最后的人。
也是唯一记录到最后的人。
他的记事本，记录着飞船各舱室的"虚假力"数据，以及一段被折叠在数据中的真相。

### 终局：黑洞
你拾起记事本，看到一条简单的航路——指向离你们最近的黑洞。

"去哪？或许，唯一的线索，只会在那儿。"

那就去吧。


## 1.2 核心隐喻（叙事的底层逻辑）

| 物理概念 | 叙事隐喻 |
| :--- | :--- |
| 虚假力（惯性力） | 系统对人的无形牵引——你以为你在自主移动，实则是系统在推你 |
| 参考系切换 | 从"被催眠"走向"觉醒"的行为映射 |
| 洞察模式 | 短暂触摸"被遗忘的真实" |
| G值 | 系统控制的强度——偏转越猛烈，你越难以察觉自己是被牵引的 |
| 马赫尘埃 | 老人留下的碎片化数据，散落在飞船各处 |
| 黑洞 | 唯一一个把"物理幻觉"与"叙事幻觉"同时压缩到极限的地方——在那里，时间折叠，过去重新显现 |


## 1.3 设计原则（贯穿全程）

1. **物理与叙事同构**：每一个机制都有叙事含义。不是"物理谜题+科幻背景"，而是"用物理讲一个关于遗忘与觉醒的故事"。
2. **玩家即船员**：玩家不是在"操作角色"，而是在"扮演一个忘了自己是谁的人"。移动的"不听话"感，就是系统催眠的体现。
3. **终点即起点**：黑洞不是"终点线"，是"让光回来的地方"——你在那里看到的，不是新世界，是被遗忘的过去。


# 第二部分：核心机制（物理层）

## 2.1 移动公式（唯一真理，不可分支）

> **最终速度 = 玩家输入 + 虚假力矢量 + 阻尼力**

三个分量同权、同时、同空间。程序不得将虚假力归入背景运动、摩擦力或自动导航。

### 分量分解

| 分量 | 来源 | 叙事含义 |
| :--- | :--- | :--- |
| 玩家输入 | WASD / 方向键 | 你"以为"自己在做的选择 |
| 虚假力矢量 | 系统（参考系加速度） | 系统对你的无形牵引——你被推向的方向 |
| 阻尼力 | `-k × velocity` | 系统对"自由移动"的压制——你越想挣脱，阻力越大 |



> **关键约束**：`fake_force` 必须作为独立矢量存在，与输入矢量做**加法叠加**。不是背景偏移，不是摩擦力，不是自动移动。


## 2.2 两大状态（常态 vs 洞察）

| 状态 | 物理层 | 视觉层 | 叙事含义 |
| :--- | :--- | :--- | :--- |
| 常态 | 三分量叠加（同右） | 无额外提示，只有轨迹偏转 | 你在"梦中"——你被系统牵引而不自知 |
| 洞察模式 | **完全相同**的三分量叠加 | ①星空定格；②蓝色实线箭头=你的输入；③红色虚线箭头=虚假力（旋转参考系中为惯性力：离心+科里奥利）；④绿色实线箭头=系统阻力（横向：阻尼物理×0.6 + 空中重力显示×0.6；旋转：圆盘向心力 -ω²R）；切换参考系时另有金色实线=目标向心力 与 紫色实线=合力（蓝+红）；箭头**按参考系单位化**绘制——普通参考系 1G、旋转参考系 10G 各对应箭头长 3 个玩家身位（96px），各参考系内同比例，合力=运动可验证；⑤屏幕左下角显示箭头图例 | 你在"梦的边缘"——你短暂看见了系统之手的形状 |

> **核心原则**：洞察模式**不关闭幻觉**，而是**揭示幻觉的几何构成**。物理层永远不分支。

## 2.3 洞察能量条（叙事含义：清醒的脆弱性）

- 按住 `Shift` 触发洞察模式，持续消耗能量条。
- 常态下，能量条以**1秒满格**的速度自动恢复（清醒的脆弱——恢复极快）。
- 普通洞察最长持续 **5 秒**；在含马赫尘埃的关卡中，**每收集 1 枚尘埃 +1 秒**（按本关累计收集数，不跨关）。
- 参考系"切换洞察"（Shift 切入直到同步）**无限时**。
- 能量耗尽时，洞察模式强制退出。
- **叙事含义**：人无法长期清醒。你只能短暂地看见真相，然后再次被拖回系统。

## 2.4 四个物理参数的叙事重定义

| 参数 | 物理定义 | 叙事隐喻 |
| :--- | :--- | :--- |
| G值 | 虚假力的大小（单位：G） | 系统对你的控制强度——G值越高，你越难察觉自己是被推动的 |
| η（惯性系数） | 输入贡献的响应灵敏度 | 你的"自我"强度——η越低，你越容易被系统裹挟；η越高，你的反抗越笨拙但更具破坏性 |
| k（阻尼系数） | 速度衰减系数 | 系统对"自由意志"的压制——k越高，你的自主移动越难延续 |
| ω（角速度） | 旋转核心的角速度 | 系统控制的非线性扭曲——转向越剧烈，你的方向感越模糊 |


# 第三部分：叙事机制（功能层）

## 3.1 老人的记事本（核心道具）

### 双重功能

1. **关卡解锁器**
   - 记事本中记录了飞船各舱室的位置。
   - 每到一个新区域，记事本会"解锁"该区域的航路信息。
   - 玩家需要根据记事本中的"虚假力数据"来预判该区域的移动偏转。

2. **剧情碎片揭示**
   - 在特定虚假加速度下，记事本边缘会浮现隐藏文字。
   - 这些文字是老人死前留下的笔记碎片，逐步揭示：地球陨落的真相、资本催眠的机制、老人为何选择深空。
   - 每一段文字，都是"被遗忘的记忆"的一次恢复。

### 交互方式
- 记事本始终显示在屏幕左下角（较小）。
- 在特定区域（如G值突变、旋转核心启动时），记事本会"发光"——此时按住 `F` 可阅读浮现的隐藏文字。
- 文字碎片不重复，逐段解锁。


## 3.2 马赫尘埃（老人数据的碎片化遗存）

- 散落在飞船各舱室中的发光粒子团。
- 按住 `E` 收集后，可主动消耗来调整 η 值（变重/变轻）。
- **叙事含义**：这些是老人留下的数据残片，被飞船系统视为"噪音"而未清除。收集它们，是在一点点恢复"被抹除的过去"。


# 第四部分：关卡结构（三幕悲剧）

## 4.1 总体结构

| 阶段 | 名称 | 场景 | 核心机制 | 叙事推进 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 系统的牢笼 | 深空号飞船内部 | 仅玩家受力（G值恒定左右偏转） | 你第一次感到"不听话"→ 按Shift看见红色箭头 → 认知觉醒的起点 |
| 2 | 幻觉的外延 | 飞船 + 天体表面 | 引入幻灵方块、马赫尘埃、绝对方块 | 你开始主动利用幻觉（控制轻重）→ 日记碎片揭示地球陨落 |
| 3 | 真相的折叠 | 黑洞附近 | 全局受力 + 旋转核心（离心力+科里奥利力） | 最终谜题 → 跃入黑洞 → 时空折叠 → 你看见了老人最后的面容 |


## 4.2 阶段1：系统的牢笼

| 项目 | 内容 |
| :--- | :--- |
| 场景 | 深空号内部走廊/舱室（封闭金属感、暗色调） |
| 幻觉范围 | 仅玩家 |
| G值 | 约 0.8（方向恒定偏转） |
| 记事本 | 无文字浮现，仅有基础航路坐标 |
| 教学 | 玩家第一次被"无形力量"拉偏 → 按Shift看见红色箭头 → 反向操作通过 |
| 关键台词（首次洞察时浮现） | "没有人在推你。你看到的红色箭头，是你所在参考系正在加速的证明——或者说，是系统在推你。" |


## 4.3 阶段2：幻觉的外延

| 项目 | 内容 |
| :--- | :--- |
| 场景 | 飞船气闸 + 小行星/天体表面（开阔感、失重感） |
| 幻觉范围 | 玩家 + 幻灵方块 |
| G值 | 约 1.2 |
| 新机制 | 幻灵方块、绝对方块、马赫尘埃 |
| 记事本 | 第一段隐藏文字浮现（条件：在G>1.0区域停留3秒） |
| 第一段文字（示例） | "他们说陨石是灾难。我说陨石是门。资本把门焊死了。" |
| 关键谜题 | 利用被虚假力"吹"到特定位置的幻灵方块垫脚过深渊；主动收集尘埃调整η改变移动特性。 |


## 4.4 阶段3：真相的折叠

| 项目 | 内容 |
| :--- | :--- |
| 场景 | 黑洞视界附近（剧烈扭曲、强光影、背景星空被拉伸成弧线） |
| 幻觉范围 | 全局万物 |
| G值 | 动态（0~3.0），距中心越远越高 |
| 新机制 | 旋转核心（离心力+科里奥利力）、记事本最终文字 |
| 最终文字（跃入前浮现） | "引力是时空告诉物质如何弯曲。虚假力是系统告诉船员如何移动。黑洞是引力把光压回原点。你是系统把记忆压回原点的那个点。" |
| 常规解法 | 利用离心力将角色甩向高处出口 |
| 隐藏解法（叙事闭环） | 顺应科里奥利力，沿螺旋轨迹落向出口下方隐藏平台——抵达后记事本自动翻至最后一页，显示老人的最后一行字："不是逃出去。是跳进去。" |


## 4.5 结局：跃向虚假力

触碰出口后：

1. 屏幕闪烁白光，所有声音骤停。
2. 画面切换至黑洞特写——一个缓慢旋转的暗色深渊，边缘泛着苍蓝色的光晕（与记事本发光颜色一致）。
3. 玩家控制的角色（或飞船）匀速滑向黑洞视界。
4. 黑洞深处**逐段浮现老人的遗言与旁白**（呈现如开场动画，逐段淡入淡出；引号段为老人遗言，暖色；不再绘制老人面孔）：

> “该说些什么呢，呵呵...”
> “恭喜你，小伙子，你看见了我留下的记号，来到了这里，看到了‘真相’”
> “你究竟是谁呢？我的同僚，还是，我曾经的敌人？”
> “不过这些都已无关紧要了。”

> 一位老人，被流放亦是流放之人，带领一群孩童来到一片蛮荒之地
> 他教会他们驻营，生火，留下生存的必须技能，随后用最无情的死亡——继续放逐来耗尽他的生命
> 或许会有一天，人们会找到他们
> 但这与他们已经无关。
> 可那又如何？
> 对于流放者而言，那些孩子并不重要，因为他确信后来者能在那星空的驱引下，用尸骸与人力开辟这片荒原
> 对于孩子们而言，流放者也不重要，因为所谓引路之人，早已是不可及之人。
> 所谓使命，也只不过是那参考系中的幻影。

5. 文字播放完毕，画面停留在黑洞（Esc 退出）。


# 第五部分：技术约束与脚本清单

## 5.1 核心约束（程序组必须遵守）

1. **`fake_force` 必须是独立矢量**：不是背景偏移，不是摩擦力，不是自动移动。与 `input_dir` 做**加法叠加**。
2. **物理层不分模式**：`_physics_process` 不因洞察模式做分支判断。
3. **所有幻觉参数来自 Area2D**：不在脚本中硬编码 G 值或 ω。
4. **记事本文字的触发条件**：由 G 值、ω 或区域进入事件驱动，不可由简单计时器触发（确保叙事与物理耦合）。


## 5.2 核心脚本清单（按开发顺序）

1. `IllusionManager.gd`（Autoload）：全局单例，存储 `current_fake_vector`、`current_g_value`、`global_influence_strength`。
2. `Player.gd`（CharacterBody2D）：移动逻辑（三分量叠加）、能量条、尘埃收集、洞察切换、箭头绘制。
3. `PhantomBlock.gd`：幻灵方块，`is_phantom` 控制是否受力。
4. `IllusionZone.gd`（Area2D）：导出变量 `g_value`、`eta`、`damping`、`omega`、`direction`。
5. `Notebook.gd`（CanvasItem）：记事本UI，控制文字浮现条件与解锁状态。
6. `Dust.gd`（Area2D）：马赫尘埃，按 E 收集。
7. `RotatingCore.gd`（Node2D）：阶段3旋转核心，驱动 ω 和背景星空。
8. `VictoryTrigger.gd`（Area2D）：触碰时触发结局演出。


## 5.3 关键参数默认值

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `speed` | 60 | 输入推力（剧情/解密统一；教学 T2=55、T3=45 为特例） |
| `jump_velocity` / `jump_gravity` | 300 / 200 | 跳跃（高度≈225px） |
| `max_speed_x` | 140 | 横向速度上限 |
| `eta` | 1.0 | 默认惯性系数 |
| `damping` | 0.5 | 默认阻尼 |
| `G_TO_ACCEL` | 10 | G→加速度换算（剧情/解密统一） |
| `ENERGY_MAX` | 100.0 | 能量条最大值 |
| `INSIGHT_DURATION_BASE` | 5.0秒 | 洞察最长持续（每枚尘埃 +1s，1秒满格恢复） |
| `ENERGY_RECOVERY` | 100.0/秒 | 恢复速度（1秒满格） |
