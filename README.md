# 《Fake Forces 善假于物》—— 操作说明（玩家手册）

> 关联项目：《Fake Forces 善假于物》（Godot 4.7 / PC，Demo）
> 文档版本：v1.0（2026-08-20，与游戏当前实现同步）
> 说明：本文档面向玩家，介绍如何运行、操作与通关本游戏。

---

## 一、游戏简介

《Fake Forces 善假于物》是一款以“参考系”与“虚假力”为核心的 2D 平台解谜游戏。
核心哲学：**“所谓力，不过是参考系中加速度的幻觉。”**

游戏包含两种模式：

| 模式 | 入口 | 内容 |
| :--- | :--- | :--- |
| 剧情模式 | 主菜单「剧情模式」 | 围绕“深空号”飞船的完整叙事：开场导言 → 三个阶段 → 黑洞结局；叙事碎片通过老人的记事本收集 |
| 解密模式 | 主菜单「解密模式」/「教学」 | 纯机制物理解谜，无剧情：教学 4 关（T1~T4）+ 主线 6 关（Q1~Q6） |

---

## 二、运行与主界面

- 运行：使用 Godot 4.7 打开工程目录后按 F5 运行，或直接运行导出的可执行程序。
- 主菜单三个入口：**解密模式**（选关）、**教学**（入门教程）、**剧情模式**（完整故事）。
- 进入剧情模式后自动播放开场导言，**按空格可跳过**。

### 暂停菜单（Esc）

游戏内按 `Esc` 打开暂停菜单：

- 继续游戏
- 重开游戏（回到本关起点）
- 返回主菜单
- 退出游戏
- 音乐音量 / 音效音量（滑条调节）

> 阅读记事本时按 Esc 不会打开暂停菜单。

## 三、键位操作表

| 操作 | 键位 | 说明 |
| :--- | :--- | :--- |
| 移动 | W A S D / 方向键 | 控制角色 |
| 跳跃 | W（落地时轻点） | 瞬时起跳；越轻（η 小）跳得越高越远 |
| 洞察模式 | 按住 `Shift` | 子弹时间（0.2 倍速）+ 受力箭头可视化，持续消耗能量 |
| 收集马赫尘埃 | 按住 `E` | 尘埃在附近时按住 E 将其吸向自己并收集 |

| 视野缩放 | 鼠标滚轮 | 仅在旋转参考系内生效（缩放倍率 0.35~2.5） |
| 暂停 | `Esc` | 打开/关闭暂停菜单 |

## 四、核心玩法机制

### 1. 三分量移动

> **最终速度 = 玩家输入 + 虚假力矢量 + 阻尼力**

- **玩家输入**：你按下的方向（WASD / 方向键）。
- **虚假力矢量**：场景幻觉场（IllusionZone）施加的独立推力，会持续把你“推”向某个方向。你以为自己在自主移动，实际上系统也在推你。
- **阻尼力**：系统对“自由移动”的压制，决定手感是滑行还是急停。

三个分量同时叠加。请勿把偏转当成操作失误——这就是游戏本身。

### 2. 洞察模式（Shift）

- 按住 `Shift` 进入洞察：时间减慢至 **0.2 倍速**，并显示受力箭头。
- 箭头图例（屏幕左下角）：
  - **蓝色实线** = 你的输入方向；
  - **红色虚线** = 虚假力 / 惯性力（旋转参考系中为离心力 + 科里奥利力）；
  - **绿色实线** = 系统阻力（横向：阻尼 + 空中重力；旋转：圆盘向心力）；
  - 切换参考系期间额外显示 **金色实线**（目标向心力）与 **紫色实线**（合力）。
- **能量限制**：普通洞察最长 **5 秒**（每收集 1 枚马赫尘埃 +1 秒）；常态下能量 **1 秒恢复满格**；能量耗尽自动退出洞察。
- **参考系切换洞察**（进入旋转参考系时的同步过程）**无限时**。
- 洞察模式不改变物理，只是揭示幻觉的几何构成。

### 3. 马赫尘埃与惯性系数 η

- 尘埃是散落的发光粒子团；按住 `E` 收集。
- 消耗 1 份尘埃：`Q` 变重（η+）、`Z` 变轻（η−），η 范围 0.3 ~ 2.5。
- η 越低越“轻”：容易被幻觉裹挟、跳得更高更远；η 越高越“重”：更稳但更笨拙（可撞碎物体）。

### 4. 参考系切换（旋转参考系）

靠近旋转核心后，按住 `Shift` 可进入“参考系切换”状态：

- 同步过程中相对速度归零即同步成功，此后角色随圆盘转动。
- 同步后操作映射：**W** 向心（靠近核心）／ **S** 离心（远离核心）／ **A** 逆时针／ **D** 顺时针。
- 持续切向加速（A/D）超过圆周速度即可“甩出”圆盘，落到其他平台。
- 旋转参考系内常规灰色平台会隐身，脱离旋转系后重新现身。
- 旋转参考系内惯性力为离心力 + 科里奥利力（幻觉显示可缩放，不影响实际受力）。

### 5. 存档点、坠落与死亡

- 触碰绿色存档点立柱即“已存档”，并重置坠落计数；剧情模式按 `R` 可回到最近存档点。
- 坠落（低于 kill_y）或触碰尖刺等危险：解密模式即时重生；剧情模式计入死亡计数，**累计超过 3 次**触发强制休眠死亡演出，之后返回主菜单。
- 到达存档点可避免坠落计数过快累计。

## 五、剧情模式通关流程

> 剧情模式 = 开场导言 → 三幕结构（阶段 1/2/3）→ 黑洞结局。

### 第一幕「系统的牢笼」（深空号内部）

- 穿过走廊过道（5 间连续房间），逐步感受幻觉推力；在某个房间收集第一枚马赫尘埃（记事本第 1 页解锁，迷宫闸门开启）。
- 走廊中会出现红色箭头提示——那是你的参考系正在被加速的证明。

### 第二幕「幻觉的外延」（迷宫 + 旋转环廊）

1. **迷宫五层塔**：逐层向上攀爬，各层存档点解锁记事本第 4~8 页剧情；在剧情触发区按 `X` 可改变该层幻觉方向。
2. **迷宫顶层出口检查**：系统会检查资料完整性（约 2 秒）。
   - 已集齐第 4~8 页 → 上层出口开启，进入中控室；
   - 未集齐 → 【非法访问】警告并黑屏，重开本关（跳过开场动画）。
3. **中控室发射**：进入发射按钮区域，按 `E` 触发黑屏跃迁，传送到旋转环廊（背景切换为太空）。
4. **旋转环廊**：跳上圆盘 → 按 Shift 切换参考系 → 甩出圆盘到达上层平台。迷宫机关与旋转核心上方平台机关分别解锁记事本第 2、3 页。

### 第三幕「真相的折叠」（环形轨道 → 黑洞）

- 进入无重力旋转环带：轨道只是视觉参考线（不站立），出生即已与环带同步。
- 用马赫尘埃把惯性系数 η 调整到对应档位，接近对应半径区即可解锁记事本剧情：
  - η = 0.3（最外圈）→ 第 9 页
  - η = 1.0 → 第 10 页
  - η = 1.7 → 第 11 页
  - η = 2.5（最内圈）→ 第 12 页
- **读完第 9~12 页后**，靠近黑洞核心（最内圈引力区）触发结局演出；未读全时靠近核心不会触发结局。
- 结局：白闪 → 黑洞特写 → 老人遗言 → 旁白 → 致谢字幕，随后自动退出游戏（Esc 可提前退出）。

| 页 | 解锁条件 | 阅读 |
| :--- | :--- | :--- |
| 第 1 页 | 收集第一枚马赫尘埃（走廊） | F |
| 第 2 页 | 迷宫机关 | F |
| 第 3 页 | 旋转核心上方平台机关 | F |
| 第 4 页 | 迷宫五层塔 L2 存档点 | F |
| 第 5 页 | 迷宫五层塔 L3 存档点 | F |
| 第 6 页 | 迷宫五层塔 L4 存档点 | F |

| 第 9 页 | 环形轨道 η=0.3，r≈600 | F |

## 八、常见问题（FAQ）

**Q：为什么角色不受控制地往一边飘？**
A：这是幻觉场（虚假力）的作用。按住 Shift 进入洞察模式看清红色箭头方向，反向补偿输入即可。

**Q：洞察模式为什么突然退出了？**
A：能量耗尽。洞察模式最长 5 秒（每收集 1 枚尘埃 +1 秒），松手后 1 秒恢复满格。

**Q：迷宫顶层的出口为什么不开？**
A：需要集齐记事本第 4~8 页（迷宫各层存档点解锁）才能通过系统检查，否则会判定为非法访问。

**Q：靠近黑洞为什么不触发结局？**
A：需要先把记事本第 9~12 页全部读完（环形轨道对应 η 档位），之后靠近黑洞核心才触发结局。

**Q：剧情模式死亡次数太多了怎么办？**
A：坠落/危险会累计死亡计数，超过 3 次触发强制休眠并返回主菜单。注意到达存档点（会重置计数），之后按 R 可回到存档点。

**Q：如何在旋转参考系里前进？**
A：同步后 A/D 切向加速、W/S 径向（向心/离心），持续切向加速超过圆周速度即可甩出圆盘。按住 Shift 可查看目标向心力（金色）与合力（紫色）。
